# Seguimiento de horas · Mesa de Soporte

Página web del tablero de seguimiento de horas reportadas en el CRM.
Para ingresar se necesita una cuenta activa; los datos se guardan en Supabase y solo son visibles con sesión iniciada.

Este repositorio solo contiene la página publicada. El código fuente se mantiene en un repositorio privado
y esta carpeta se genera con `construir_nube.py`.
